## 版本约定

- `x.y.z`：正式版本，可从 Maven Central 获取；
- `x.y.z-rc.n`：候选版本，API 仍可能调整；
- `x.y.z-SNAPSHOT`：开发快照，不保证稳定或长期可获取；
- 废弃 API 会先标注 `@Deprecated`；具体移除计划以对应版本的迁移文档为准。

项目概览、安装坐标和最短示例见[根 README](../README.md)。
