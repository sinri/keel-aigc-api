# Agent

本包提供一套 AGENT 的框架，允许在提供 TOOLs 和 SKILLs 的基础上，通过 AGENT 的调度，通过 LLM 多轮对话实现完整的用户请求执行。

## 工具调用

定义一个接口，一个接口的实例对应一个 function 类型的工具调用实例。

提供一个 Agent Tool 会话管理器，允许用户将上面的接口实例注册到管理器中，管理器会根据用户请求，调用相应的工具接口。

## 技能调用

定义接口来支持 SKILL 的读写。可以暂且仅支持文件系统类型。

在 AGENT 中运行加载 SKILLs，通过 AGENT 的调度，由 LLM 引用所需 SKILL 加以运用。
